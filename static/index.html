3. Manual GPT

Manual ChatGPT fallback

This does not use your website API credit. It builds two prompts from the title, target age, Detailed Description, and character names entered in the Live Generator above.

Fresh redesign rule: every new artwork attempt should start in a brand-new ChatGPT conversation. Re-upload only the original source photos, then paste a newly generated Prompt 1. Do not reuse old AI artwork as a reference.

Prompt 1 — Create artwork

Start a NEW ChatGPT conversation, upload the original source photo(s), then paste this prompt. It creates 1 cover + 20 individual coloring pages and stops for review.

Prompt 2 — Build PDF

When the artwork is approved, paste this into the SAME ChatGPT conversation. It creates the 24-page print-ready PDF.

Manual 24-page structure: page 1 cover · page 2 blank · pages 3–22 twenty individual coloring pages · pages 23–24 blank. Prompt 2 requires true 8.5 × 11 inch PDF pages.
