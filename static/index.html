2. Live Generator

Create a live personalized book

Upload one or more people and generate a live AI book. Each generation receives a new hidden Book DNA creative fingerprint so identical customer inputs can still produce different story structure, scene order, activities, compositions, pacing, and visual motifs. The automatic version creates a high-quality color cover plus 8 coloring pages, with individual medium-quality retries for weak interior pages. Start by adding the people who will appear in the book, then enter your title, age, and description. If you need help thinking of an idea, the optional Idea Generator below can build or randomize the concept for all of your added people.

Age 3–4 uses preschool-simple pages: extra-thick outlines, huge coloring spaces, very few objects, and lots of white space. Detail increases gradually for older kids and teens.

3. Manual GPT

Manual ChatGPT fallback

This does not use your website API credit. It builds two prompts from the title, target age, Detailed Description, and character names entered in the Live Generator above—including multiple character names, titles, descriptions, and tones filled in by the optional Idea Generator. Every time you generate Prompt 1, the site also creates a new hidden Book DNA so repeated customer inputs are pushed toward a materially different 20-page scene sequence. The Story Mode toggle above is carried into both manual prompts.

Fresh redesign + uniqueness rule: every new artwork attempt should start in a brand-new ChatGPT conversation. Re-upload only the original source photos, then paste a newly generated Prompt 1. Each newly generated Prompt 1 contains a different Book DNA creative fingerprint. Do not reuse old AI artwork as a reference.

Prompt 1 — Create artwork

Start a NEW ChatGPT conversation, upload the original source photo(s), then paste this prompt. It contains a unique Book DNA for this attempt, creates 1 cover + 20 individual coloring pages, and stops for review. If Story Mode is on, it also requires one continuous 20-page plot and an exact narration list for the final PDF.

Prompt 2 — Build PDF

When the artwork is approved, paste this into the SAME ChatGPT conversation. It creates the 24-page print-ready PDF.

Manual 24-page structure: page 1 cover · page 2 blank · pages 3–22 twenty individual coloring pages · pages 23–24 blank. Prompt 2 requires true 8.5 × 11 inch PDF pages.
